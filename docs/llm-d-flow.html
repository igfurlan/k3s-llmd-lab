The model servers are simulators emitting vLLM's own metric names, so the gateway, the scheduler and every dashboard behave exactly as they would against real vLLM. The KV transfer is modelled rather than performed. What this lab proves is where the scheduler sends requests and what that costs — not what a cache hit is worth in seconds, which needs real weights on real accelerators.
